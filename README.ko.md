# Tray Tasks

옵시디언을 열지 않고 데일리 노트의 할 일을 관리하는 Windows 위젯·트레이 앱입니다.

**0.5.0 개발 미리보기**입니다. 정식 V1.0.0은 사용 환경 검증 이후 진행합니다.

## 시작하기

1. Windows 설치 파일을 실행하고 Tray Tasks를 엽니다.
2. 옵시디언에서 **설정 → 코어 플러그인 → 데일리 노트**를 켜고 날짜 형식을 **YYYY-MM-DD**로 설정합니다.
3. 앱에서 볼트 폴더와 데일리 노트 저장 폴더를 선택합니다. 저장 폴더를 비워두면 볼트 최상위 폴더를 사용합니다.
4. 설정 확인 후 저장하면 작업표시줄 오른쪽 알림 영역의 아이콘으로 목록을 열 수 있습니다. 아이콘이 숨겨져 있다면 펼치기 메뉴에서 밖으로 드래그하거나 Windows 작업표시줄 설정을 이용하세요. 표시 위치는 Windows가 관리합니다.

컴퓨터를 켰을 때 시작하려면 설정에서 **Windows 로그인 시 자동 실행**을 켜세요. 설정 이후에는 위젯을 표시하고 목록과 Obsidian 창은 열지 않습니다.

## 사용법

- 위젯은 미완료 할 일 하나를 표시합니다. 주 작업표시줄의 알림 영역 바로 왼쪽에 자동 배치되며 배경은 투명합니다. 이동 손잡이는 없고 높이는 작업표시줄에 고정됩니다. 아이콘을 다시 누르면 전체 목록이 닫힙니다. 다음 버튼은 완료 처리 없이 항목만 넘기며 선택은 재시작 후 유지됩니다. 알림 영역을 감지하지 못하면 저장된 가로 위치를 사용합니다.
- 체크하면 완료 목록으로 이동합니다. 완료 목록에서 체크를 해제하면 다시 미완료 항목이 됩니다.
- 이름을 우클릭하거나 두 번 클릭하거나 F2를 누르면 수정할 수 있습니다. Enter 또는 다른 곳을 눌러 저장합니다.
- 왼쪽 손잡이로 드래그하면 놓을 위치에 따라 목록 순서가 바로 바뀝니다. 들여쓴 체크박스도 독립된 할 일로 다룹니다.
- 삭제와 미루기는 선택한 체크박스 한 개에만 적용합니다. 다른 항목이나 들여쓴 내용은 유지합니다.
- 미루기는 내일 / 다음 주 같은 날 / 직접 선택으로 제공합니다. **수동 미루기는 알림을 해제**합니다.
- 리마인더 버튼을 누르고 항목을 클릭하면 오늘·내일과 시·분 스크롤로 시간을 정할 수 있습니다. **현재 시각 이후부터 내일 23:59까지** 선택한 뒤 **적용**해야 저장됩니다. 취소하면 임시 설정과 임시 해제가 모두 취소됩니다.
- 알림 창 오른쪽의 작은 확인 버튼은 표시된 알림을 해제하며 할 일 자체를 완료하지는 않습니다. 할 일 아래의 예약 시각은 알림 창에 표시하지 않습니다.
- 자정 이월에 동의하면 전날 항목을 완료하고 오늘 항목을 새로 만듭니다. **예약된 알림 시각은 그대로 유지**합니다.
- 자정 이월을 거절하면 전날 항목은 유지하고 아직 울리지 않은 알림만 해제합니다.

목록 끝의 추가 버튼을 누르고 빈 행에 이름을 입력한 뒤 Enter 또는 다른 곳을 눌러 저장합니다. 빈 이름은 생성되지 않습니다. 할 일 5개와 추가 버튼까지는 스크롤 없이 표시됩니다. 280px 목록과 팝업은 바깥 테두리 없이 표시되며 긴 제목은 초당 14px의 일정한 속도로 가로 스크롤됩니다. 팝업은 그림자 없이 목록 위에 열리며 목록을 클릭하면 취소됩니다. 잘못된 미루기 날짜는 팝업 안에 오류를 표시합니다. 설정은 독립된 창이고 다른 곳을 눌러도 자동으로 닫히지 않습니다. 취소·저장 후에는 목록으로 돌아옵니다.

새 항목은 기본적으로 문서 끝에 추가합니다. 읽을 제목과 추가할 제목을 각각 설정할 수 있습니다. 읽기 범위를 지정했다면 추가 위치도 그 범위 안에 있도록 맞추세요.

항목 ID는 `<!-- tray-tasks:UUID -->`로 마크다운 원문에 남습니다. 읽기 화면에서는 보이지 않습니다. 수동으로 미룬 원본에는 `[>]` 상태와 날짜 링크가 남습니다.

## 개발 실행

Node.js, Rust, Visual Studio C++ 도구, Windows SDK 설치 후 프로젝트 폴더에서 실행합니다.

```powershell
npm ci
npm run desktop:dev
```

테스트는 `npm test`, `npm run desktop:test`, 설치 파일 생성은 `npm run desktop:build`입니다.

구현 설명과 검증 범위는 [영문 README](README.md), [구조](docs/architecture.md), [검증 기록](docs/testing.md)을 참고하세요. 설정과 백업은 보통 `%LOCALAPPDATA%\com.traytasks.obsidian`에 있습니다.

실제 Windows 로그인 시 자동 시작, 설치·업그레이드, 다중 모니터에서의 최종 검증은 남아 있습니다.
